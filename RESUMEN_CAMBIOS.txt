🚀 LO QUE NECESITAS HACER EN 5 MINUTOS:

1. Crear repositorio: https://github.com/new
   → Nombre: atlas-histologia
   → IMPORTANTE: Marcar PUBLIC ✓

2. Subir código:
   git init
   git add .
   git commit -m "Atlas Virtual de Histología"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/atlas-histologia.git
   git push -u origin main

3. Activar GitHub Pages:
   Settings → Pages → Deploy from a branch → main/root → Save

4. Esperar 2 minutos ⏳

5. Acceder a: https://TU_USUARIO.github.io/atlas-histologia/

🆘 PROBLEMAS COMUNES:

❓ El sitio no aparece
   → Espera 5 minutos
   → Verifica que el repo sea PUBLIC
   → Ve a Actions y busca errores

❓ Los estilos se ven mal
   → Vacía caché: Ctrl+Shift+Delete
   → Recarga: Ctrl+F5

❓ Las imágenes no cargan
   → Verifica que estén en public/images/
   → Usa rutas que empiezan con /

❓ No funciona el script deploy.sh
   → Asegúrate de tener Git instalado
   → Ejecuta: chmod +x deploy.sh
   → Luego: bash deploy.sh
